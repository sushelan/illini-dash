Illini Dash — Settings

Checking service worker…

Sources

The sites you picked when you set up. Turning one off stops it being read and stops it counting toward the health line — switch one back on here if you start a course that uses it.

Each source is read using the login session already in your browser. Nothing here ever sees a password (SPEC.md §0).

Courses

Every course seen across every source. Turning one off hides its deadlines without forgetting them.

Older courses

Canvas still lists these as active, but they belong to a term that is not the current one — usually a compliance or onboarding course that never closes. Their deadlines are left out of the list. If one of these is a course you are really taking, put it back.

Course websites

Some courses keep the real schedule on their own site. These adapters are plain data — a URL and a few CSS selectors — so a broken one can be fixed without updating the extension. Enabling one asks Chrome for permission to read that site, which is why they are not requested up front.

Reminders

Hidden items

Ticked off

Work you marked done yourself. Some sources — course websites, and anything handed in on paper — never report a submission, so this is the only way those rows can be finished. If a source later says the work is missing, the row comes back on its own.

Calendar

Downloads an .ics of everything currently listed. Importing it into Google Calendar is a one-time copy, not a subscription — later changes to a deadline will not follow it there.

Data

Copy diagnostics puts a summary on your clipboard — which sources worked, how many items each course produced, and what failed. It contains no assignment titles, no links and nothing that identifies you, so it is safe to paste into a bug report. Export JSON is the opposite: your whole list, for keeping.

Report a broken page

If a source is showing a red dot, or a deadline you can see on the site is missing from the list, this fetches that page, removes what it can recognise as yours, and hands you a file to attach to a GitHub issue. Nothing is sent anywhere automatically.


Used only to remove them from the file. Without them nothing is removed.

Privacy

Developer tools

Diagnostics for building and debugging the extension. Nothing here runs on its own, and none of it is needed to use Illini Dash.

Gate 0 — cookie-authenticated fetch from the service worker

Fetches each source's authenticated home page from the extension's service worker with credentials: "include" (SPEC.md §2.2, §9 G0). Log in to all four sites in this browser profile first. Results are also logged to the service worker console; nothing is stored.

Offscreen parser round-trip

Sends HTML from the service worker to the offscreen document, runs a throwaway parser there, and brings RawItem[] back (SPEC.md §2.1, build step 3). Also checks that a structurally-empty page comes back as a ParseError rather than an empty list (§0 rule 3).

Fixture capture

Fetches a page from the service worker exactly the way the sync loop will, scrubs it per Appendix A, and hands it back as a download. Save the scrubbed file into fixtures/<source>/. Nothing is fetched or saved automatically (SPEC.md §10 step 4, §9 G1).
