Settings

Sources

The sites Illini Dash reads your deadlines from.

Why does it need these?

Each one is read using the login session already in your browser, the same way a second tab would be. Nothing here ever sees a password, and nothing leaves your computer. Switching a source off stops it being read and stops it counting toward the line at the top of this page.

Courses

Every course seen across every source. Switching one off hides its deadlines without forgetting them.

Older courses

Canvas still lists these as active, but they belong to an earlier term — usually a compliance course that never closes. Their deadlines are left out. If one of them is a course you are really taking, put it back.

Course websites

Some courses keep the real schedule on their own site.

Why are these separate?

A course website is just a URL and a few CSS selectors, so a broken one can be fixed without updating the extension. Switching one on asks Chrome for permission to read that one site, which is why they are not requested up front.

Add a course site

Paste the page that lists your deadlines. It is read once, and you get to check what it found before anything is saved.

Reminders

A Chrome notification before something is due.

Appearance

Presets rather than a colour picker.

Why not let me pick the colours?

Colour here carries meaning — red is overdue, amber is a window still open, green is a source that answered. A free choice lets two of those end up the same colour, and the result looks fine and lies.

Hidden & done

Rows you put away, and the way back.

Hidden

Ticked off

Work you marked done yourself. Course websites, and anything handed in on paper, never report a submission — so this is the only way those rows can be finished. If a source later says the work is missing, the row comes back on its own.

Build and background worker

Checking the background part…

Gate 0 — cookie-authenticated fetch from the service worker

Fetches each source's authenticated home page from the extension's service worker with credentials: "include". Log in to all four sites in this browser profile first. Nothing is stored.

Offscreen parser round-trip

Sends HTML from the service worker to the offscreen document, runs a throwaway parser there, and brings RawItem[] back. Also checks that a structurally-empty page comes back as a ParseError rather than an empty list.

Fixture capture

Fetches a page the way the sync loop will, scrubs it per Appendix A, and hands it back as a download. Save the scrubbed file into fixtures/<source>/. Nothing is fetched or saved automatically.
